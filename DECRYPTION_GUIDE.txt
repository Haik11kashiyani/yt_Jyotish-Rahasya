================================================================================
                         TROUBLESHOOTING
================================================================================

ERROR: "Python was not found"
FIX: Install Python 3.11 using winget or from python.org

ERROR: "'pip' is not recognized"
FIX: Python not in PATH. Reinstall with "Add Python to PATH" checked.

ERROR: "ModuleNotFoundError: No module named 'cryptography'"
FIX: Install it: pip install cryptography

ERROR: "ENCRYPTION_KEY not found or invalid"
FIX: Set the key before running decrypt commands:
    $env:ENCRYPTION_KEY = "gEDjRSzuVgmOAANo2mjCjZ0R+T/rKAabssu4quhx8KGOajounWo6Lp1lKc2aR1I7NOYxwsXgrHba"

ERROR: "Invalid token - decryption failed"
FIX: Key doesn't match. Verify you're using the correct ENCRYPTION_KEY.

ERROR: "File not found: .encrypted.py"
FIX: File may not exist or wrong path. Use relative path from repo root:
    python crypto_utils.py decrypt agents/astrologer.encrypted.py  ✓
    NOT: python crypto_utils.py decrypt C:\...\agents\astrologer.encrypted.py  ✗
